# 小王子：纸间星旅（Godot 工程）

**3D 星球互动叙事**

> 一场穿行于六颗 3D 星球之间的互动叙事。与人物对话，旋转、观察并触碰场景，理解六位“大人”的困境；收集星光，最终亲手创造属于自己的第七颗星。

## 打开方式

1. 启动 `E:\Godot 4\Godot_v4.7.2-stable_win64.exe`。
2. 在项目管理器中选择“导入现有项目”。
3. 选择本目录中的 `project.godot`。
4. 按 `F6` 或 `F5` 运行。

开发调试时可以双击项目根目录的 `打开Godot编辑器_安全模式.cmd`。注意：当前 Godot 4.7.2 的调试运行器（`F5`）即使指定原生 OpenGL，仍会强制附加 ANGLE；需要实际游玩或验收 3D 场景时，请使用 `启动游戏_安全模式.cmd`。

3D 星球场景和星盘中可按 `F10` 一键隐藏或恢复界面，再按 `F12` 截取无 UI 的整个游戏视口。PNG 文件会保存到 `C:\Users\ctyb\Desktop\截图`。

也可以直接双击 `project.godot`。

## 目录结构

- `scripts/`：游戏运行时脚本。
- `assets/`：运行时模型、界面、声音与字体。
- `shaders/`：运行时着色器。
- `docs/`：设计、界面和美术提示词，不参与运行时加载。
- `tools/`：回归验证与一次性开发工具，不参与运行时加载；测试图片写入被 Godot 忽略的 `tools/test_output/`。
- `addons/specqr/`：信纸二维码功能依赖。
- `.godot/`：本机导入缓存，由 Godot 自动生成，不纳入源码交付。

所有 GLB 都已内嵌纹理，项目不再保留重复的旁置 PBR PNG/JPG 源图。旧版资源与测试输出已移出工程。

## 点灯人对话与落座

## 星球布局编辑器

- 进入点灯人 3D 场景后，点击右上角“编辑布局”打开面板。
- 旋转到满意的正面朝向后，点击“将当前朝向设为初始视角”，即可按星球分别保存重新进入与双击复位时使用的朝向。
- “画面高度”中的“星球上移 / 星球下移”按钮可按星球分别调整初始构图；高度与朝向会一起保存，并随星球自动恢复。
- 可在对象下拉列表中选取，也可以直接点击星球上的对象；拖拽星球表面即可重新落地和移动。
- 点选使用更宽松的屏幕包围范围，结合相机射线、对象深度和星球遮挡判断；点到对象附近即可选中，点到空白仍旋转星球。
- 点击对象时拖动的是对象；点击空白区域时则旋转查看整颗星球，不再误拖当前选中对象。
- 缩放范围和朝向范围分别为 `30%–300%` 和 `-180°–180°`。
- “离球心”滑杆可在 `1.50–3.50` 范围内调整对象到球心的距离，并实时更新接地高度。
- “复制对象”会复制完整节点、材质引用、灯光和当前缩放朝向，并将副本移到相邻球面位置。
- “显示此物体”可用于让默认隐藏的椅子和坐姿小王子参与布局。
- “恢复当前”会恢复当前对象的位置、缩放、朝向和默认显隐。
- “保存布局”同时写入 `user://pointlighter_layout.json` 和项目根目录的 `pointlighter_layout.json`；再次进入时优先读取用户布局。
- 默认可编辑对象共 20 个：7 个主体与角色、4 棵树、1 条石板路、3 组石块和 5 簇草。
