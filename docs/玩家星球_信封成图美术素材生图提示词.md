# 玩家星球 · 信封成图美术素材生图提示词

## 一、使用说明

目标是制作玩家拍照后的手机保存图。整体采用竖向 5:7 排版，文字和照片都在运行时合成，因此生成素材中必须保留干净的文字区与照片区，不要生成任何文字、数字、伪文字、二维码或真实照片。

用户示意图中的红、绿、紫、蓝区域只表示内容位置，不是最终颜色。最终画面应全部统一为项目现有的暖纸雕、深蓝星盘、旧金压边与少量铁锈橙配色。

推荐拆分为以下素材：

1. `letter_result_backdrop.png`：完整竖向信封与信纸底板。
2. `letter_photo_matte.png`：横向照片底板与纸雕边框。
3. `letter_wax_seal.png`：橙色热熔章。
4. `letter_postage_stamp.png`：纸雕邮票。
5. `letter_photo_fixings.png`：胶带、纸角和星形别针。
6. `letter_qr_plaque.png`：二维码纸牌边框。
7. 可选：一张同页素材总览，用于统一生成与拆分。

所有成品建议输出高分辨率 PNG，sRGB；主底板建议 `2560×3584`，照片框建议 `2048×1280`，圆形章和邮票建议不低于 `1024×1024`。

## 二、统一美术方向

### 通用正向风格

```text
高级手剪纸雕，旧童话立体书质感，多层哑光纸张拼贴，儿童绘本式温柔插画语言。请直接继承《小王子 · 纸雕星图》现有 UI 的视觉体系：暖象牙纸、奶油白、旧金色压边、焦糖棕、低饱和午夜蓝、雾蓝和少量铁锈橙。纸张有极轻的天然纤维、手剪形成的细微不规则边缘、浅折痕、压痕和局部毛边；纸层厚度清楚，但不要把边缘做成粗糙撕裂的纸板。左上角暖光照入，层与层之间只有短、柔、干净的接触阴影。整体安静、精致、童话、手作，不能抢人物和星球主体。
```

## 三、整体竖向底板

### 用途

作为最终成图的主背景。运行时在空白区叠加玩家输入的星球名、归类、叙述、“你做了什么”和“星球回声”，最下方再覆盖照片底板。

### 主提示词

```text
生成一张竖向 5:7 的纸雕游戏结果卡背景，高级手剪纸雕与旧童话立体书质感，多层哑光纸拼贴，专门用于《小王子 · 纸雕星图》玩家星球拍照后的纪念信。画面像一封从深蓝星盘中缓缓抽出的信：最外层是低饱和午夜蓝与雾蓝叠成的打开信封，信封内衬有极淡的星座连线、纸雕星点和一圈不完整的旧金细圆环；中央是一张暖象牙色厚纸信笺，纸页轮廓略微自然起伏，左上和两侧被深蓝纸层托住，边缘保留干净手剪毛边与薄薄叠层阴影。

信纸不是现代卡片，而是一页温柔的手工童话书写纸。纸面以暖象牙色和奶油白为主，有极轻的天然纤维、浅折痕与局部压痕；边缘由两三层深浅不同的米白、浅灰米黄薄纸构成，厚度约一片纸，不得厚重。信笺内部用非常克制的旧金压线和细小纸雕星点划分层次：顶部留一条较宽的空白标题区，标题区左侧预留一个圆形无图案章位；标题下方留一条窄的空白归类区；中段保留大面积连续书写留白；下部保留足够空间放置横向照片底板。所有区域都要连成一张完整的信纸，不能用现代分隔条、彩色文本框或生硬矩形面板切块。

构图要求：竖向比例稳定，信纸占画面宽度约 78% 至 84%，四周留出深蓝信封纸边；顶部略高，底部略沉，形成可以托住照片的视觉重心。橙色热熔章位、星球名称位、归类位、正文位和照片位之间必须留出清楚的空白，不互相挤压。画面中只能有信封、信纸、纸张层、旧金压线、少量星点和细微纸雕装饰，不出现任何可读文字、照片、二维码或人物。左上暖光，投影短、柔、干净；纸张边缘有自然手作微差；整体安静、细腻、能直接作为游戏成品底板。
```

```text
真实邮票，真实火漆，完整信封封口，人物，星球插画，照片缩略图，二维码，文字占位符，乱码，重复星形
```

## 四、横向照片底板

### 用途

照片会在运行时覆盖中央空白矩形，因此底板只负责深蓝衬纸、旧金压线、米白卡纸和边角装饰。不要把照片或星球插画生成进底板。

### 主提示词

```text
生成一张横向 8:5 的纸雕照片底板，纯透明背景，物件悬空展示，无场景。它属于《小王子 · 纸雕星图》的手工纪念信，需要像一张从旧童话书里取出的相片卡：最底层是一片略不规则的低饱和午夜蓝薄纸，中层是暖象牙厚卡纸，最上层在中央留出一个横向 8:5 的干净空白矩形，供游戏运行时覆盖玩家拍下的星球照片。

外轮廓由两到三层错位的午夜蓝、雾蓝和奶油纸叠成，纸边有极轻手剪起伏与自然折角，厚度克制，投影短而柔。中央照片窗口四周有一圈非常细的旧金压线，像手工压出的相框内沿，不能像金属相框。左上角叠一枚很小的旧金纸星星，右下角有一小片翻起的奶油纸角，纸角背面为浅浅雾蓝；装饰只占边角很小面积，确保照片主体完全无遮挡。整体正放、水平、居中、平直，四周保留充足透明留白；实际成图时由游戏将整张照片卡轻微旋转约 1 至 3 度。

画面中只能出现空照片底板、纸张层、细压线和少量纸雕边角装饰。不要生成照片内容、人物、星球、天空、文字、数字、二维码、胶带、图钉或真实相框。
```

### 追加负面提示词

```text
照片内容，截图，星球风景，人物，真实木质相框，玻璃，金属相框，厚重大边框，白色现代相框，圆角手机图框，
底板已经倾斜，透视变形，装饰覆盖照片区，中间出现花纹，中间出现文字，贴边裁切
```

## 五、橙色热熔章

### 用途

单独透明 PNG，运行时放在信纸左上或标题区左侧，覆盖在纸面上，负责成品图的完成感。章面不要生成星球名，名字和归类由程序排版。

### 主提示词

```text
生成一枚俯视视角的橙色热熔火漆章，纯透明背景，单个物件，中心居中，完整不裁切。风格必须属于《小王子 · 纸雕星图》的手工童话纪念信：颜色使用稍低饱和的铁锈橙与焦糖橙，像手工熔蜡自然压成，不是塑料圆片，也不是高亮红宝石。章体为圆形，外缘有自然不规则、轻微熔流和几个很小的圆钝滴落边，厚度适中；受光面柔和，中心略微压凹，表面有极轻的蜡质起伏和压纹，但整体应接近哑光，不能油亮。

章面浮雕图案采用非常简洁的纸雕童话语言：一枚小星球轮廓，上面一朵简化的纸雕玫瑰，旁边有两三颗小星；线条圆钝、刻印浅、识别清楚，但不能太细碎。图案必须与橙色章面同色系形成轻微压印，不要使用金色亮面、银色亮面或黑色粗线。章体占画布约 72%，四周保留充足透明留白，正面俯视，中心与边缘厚度一致，适合直接缩放到 180 至 260 像素后仍清楚。

不要出现文字、字母、数字、缩写、复杂纹章、王冠、人物脸、二维码、金属光泽、塑料高光、现代徽章、绳带、信封、纸张背景或多个印章。
```

## 六、纸雕邮票

### 用途

作为信封感的小型装饰，可放在正文下缘、照片底板角边或二维码纸牌附近。邮票不承担实际邮寄功能。

### 主提示词

```text
生成一枚单独的纸雕纪念邮票，竖向接近 4:5，纯透明背景，无纸张背景，无信封。整体沿用《小王子 · 纸雕星图》的暖象牙纸、低饱和午夜蓝、雾蓝、旧金和焦糖棕配色。邮票外形为传统矩形齿孔邮票，但齿孔必须柔和、细小、手工裁切感明显，不能像现代撕票或金属邮票。纸张为哑光旧象牙色，有极轻纤维和浅折痕，边缘厚度很薄，左上有轻微旧金暖光，右下有极淡短投影。

邮票内部只画一个完整而简洁的纸雕星夜小景：深蓝叠纸上有一枚暖奶油色小星球、一朵极小玫瑰和两颗旧金星，构图像儿童绘本插图，留出温柔的蓝色负空间。纸雕层次不超过四层，色块大、轮廓圆钝、缩小后仍能辨认。邮票左侧保留一条没有内容的旧金细竖线，像收藏册的压线；不要写面值、国名、日期或任何字母。

单个邮票正面展示，居中，完整，四周透明留白充足。不要生成信封、信件、人物、狐狸、动物、多个邮票、连接纸边、文字、数字、伪文字、二维码、水印或写实邮政元素。
```

## 七、照片固定装饰

### 用途

用于让照片看起来轻轻歪放、被固定在一张信纸上。建议生成一页透明小素材，运行时只选一到三件叠加。

### 主提示词

```text
生成一张透明背景的纸雕照片固定装饰素材页，正方形画布，共六件独立小素材，整齐分成 2 列 3 行，彼此不接触、不重叠、四周留足透明间距，方便单独抠图。统一采用《小王子 · 纸雕星图》的暖象牙纸、旧金、焦糖棕、低饱和午夜蓝和雾蓝，纸张哑光，手剪边缘极细，接触阴影短而柔软。

第一行：一片奶油白半透明撕纸胶带，边缘极轻毛糙；一片雾蓝半透明撕纸胶带，形态与第一片接近但不完全相同。
第二行：一枚暖米白三角照片角贴，纸面有很轻压痕；另一枚镜像方向的三角照片角贴。
第三行：一枚小型旧金纸雕星形别针，只表现扁平纸片和短钉，不做尖锐现实图钉；一枚小型纸雕星芒贴纸，由两层米白与旧金纸组成。

六件素材都像从同一页旧童话手作工具纸上剪下，比例合理，无文字、无人物、无照片、无完整相框、无纸张背景。不要现代和纸胶带商标，不要塑料透明胶带，不要金属回形针，不要多个相同造型。
```

## 八、二维码纸牌

### 用途

二维码由程序生成后覆盖在中央平色区域。素材只负责一块像手作纸牌的外框。

### 主提示词

```text
生成一张单独的方形纸雕二维码纸牌外框，正方形 1:1，纯透明背景，正面俯视，完整居中。整体是一位小小收藏家在信上留下的一块手作提示牌，必须与《小王子 · 纸雕星图》现有纸卡一致：最底层是低饱和午夜蓝不规则薄纸，中央是暖象牙色厚纸小牌，外缘有极细手剪毛边和浅折痕，四周有一圈很窄的旧金压线。中央保留一个规则、干净、纯平的暖奶油色正方形空白区，供游戏运行时覆盖二维码，不画任何点阵。

顶部和左侧各有一小片轻微错位的奶油纸边，左上角可放一颗很小的旧金纸星，右下角可有一个极小的卷纸角。纸张是哑光薄纸，层厚克制，左上暖光，接触阴影短而柔。整体安静、精致、可缩小到 160 至 240 像素后仍清楚，不能抢照片主体。

不要出现二维码、条形码、文字、数字、图案、logo、现代圆角卡片、玻璃、塑料、金属铭牌、图钉、绳带、人物或背景场景。
```

## 九、同页素材总览

### 用途

如果生图工具更擅长一次性生成资产板，可用这一页生成后拆分。实际合成仍建议使用单独素材，避免抠图边缘损坏。

### 单张四分区生图提示词

```text
生成一张正方形 1:1、约 4096×4096 的纸雕游戏美术资产板，纯白色无纹理背景，用于后期逐件抠图。主题是《小王子 · 纸雕星图》玩家星球纪念信封的装饰素材。高级手剪纸雕、多层哑光薄纸拼贴、旧童话立体书质感；暖象牙纸、奶油白、旧金、焦糖棕、低饱和午夜蓝、雾蓝和少量铁锈橙。纸张有极细天然纤维、浅折痕、手剪毛边和很短的柔和接触阴影，统一从左上接受暖光。

画布严格分成 2×2 四个互不重叠的象限，每个象限内只放指定素材；所有素材完整展示、居中、轮廓清楚，四周以及与相邻象限之间都保留充足纯白间距，不跨越分界线，不贴画布边缘，方便后期逐件抠图。

左上象限：一枚俯视视角的橙色热熔火漆章，稍低饱和的铁锈橙与焦糖橙，圆形章体边缘自然不规则，有少量圆钝熔流和很轻的中心压凹；章面只有小星球、简化纸雕玫瑰和两三颗小星的低浅同色压印。章体像手工熔蜡，接近哑光，不要塑料高光和金属徽章感。

右上象限：一枚竖向约 4:5 的纸雕纪念邮票，传统矩形细齿孔边框，暖象牙旧纸，极薄边缘和短柔投影；内部是深蓝与雾蓝叠纸上的奶油色小星球、一朵微型玫瑰和两颗旧金星。图案只用三四层大色块，缩小后仍清楚；不画面值、国名、日期或任何字母数字。

左下象限：一页六件独立照片固定装饰，整齐分成 2 列 3 行，彼此不接触。包括两片形态不同的奶油白与雾蓝撕纸胶带、两枚互为镜像的米白三角照片角贴、一枚扁平旧金星形纸别针、一枚米白与旧金双层星芒贴纸。所有纸片像从同一本旧童话手工工具页裁下，不要现代塑料胶带有光泽，不要尖锐金属图钉。

右下象限：一块方形手作二维码纸牌外框，由一个低饱和深蓝不规则薄纸底层和一块暖象牙厚纸小牌组成；中央保留规则、干净、纯平的暖奶油色正方形空白区，供程序覆盖二维码。牌面只有极细旧金压线、很小折角和一颗微型旧金纸星，不画二维码点阵。

四组素材的配色、纸张厚度、毛边密度、装饰克制程度、光照方向和接触阴影必须完全一致，像从同一套旧童话手工纸中制作出来。不要出现文字、数字、伪文字、商标、签名、水印、编号、二维码、真实照片、人物、完整星球场景、信封、主信纸或照片边框。不要物件互碰、重叠、重复、贴边裁切，不要写实 3D、玻璃、塑料、霓虹或现代 App 图标。
```

## 十、最终排版参考提示词

### 用途
