# 爱慕虚荣者星球 · 3D 资产清单

## 整理口径

场景以现有 `assets/planets/vain-awake.png` 和 `vain-dormant.png` 为视觉基准：珍珠白小星球、淡紫岩石、云母蓝镜面、圆顶镜亭、花瓣状立镜、细金环，以及漂浮的淡紫纸片和雾带。剧情与交互依据 `星球文本_定稿草案.md`，核心动作为“为他鼓掌”。

当前只有星图双态图，尚无该星球的 3D 模型。首版目标为低模纸雕质感、可独立编辑，完整场景约 **30–32 万三角面**、**45 MB 以内**。50 MB 是本场景的硬上限，不按单个文件计。

建议目录：

```text
GodotProject/assets/3d/vain/
```

## 复用与场景外资产

| 现有文件 | 用途 |
| --- | --- |
| `looking_up_prince.glb` | 若暂不制作鼓掌姿势，可用现有抬头王子作为加载与回退模型；正式交互仍建议使用 `vain_prince_applaud.glb`。 |
| `rocks.glb` | 可作为远景岩块回退资源，但需要换成珍珠灰紫材质。 |
| `round_tree.glb` / `grass.glb` | 可在星球背面极少量使用，正面不要加入绿色植被，保持参考图中“镜面花园”的冷色纯度。 |

以下内容不建议做成独立 GLB：

- 飘在星球后的淡紫雾带：沿用 Godot 程序化云带和半透明纸带材质。
- 背景星空、浮尘、光晕：由场景环境和粒子完成。
- “一百面镜子”的文字：使用 UI 或 `Label3D`，不要烘进模型贴图。
- 掌声按钮、交互提示与台词：属于界面层。
- 全部镜面实时反射：性能成本过高，首版只给中央主镜或画面正中的两至三面镜启用低成本反射。

## 镜面表现约束

- 主镜面使用独立的 `MirrorGlass` 材质，粗糙度约 `0.16–0.28`，避免成为纯白发光板。
- 反射优先使用近似天空纹理、假倒影和一层天空蓝高光；只有中央镜面允许使用实时反射探针或渲染目标。
- 镜片背面必须是实体薄壳并带有淡紫背板，不能只做单面面片，否则旋转星球时会看见空洞。
- 掌声停止后通过降低镜面亮度、增加冷灰和轻微去饱和表现“倒影老了一岁”，不单独制作第二个人物模型。
- 镜框金属为低光泽淡金，不能使用写实镀铬。

## 建议动画与交互

| 对象 | 动画或交互 |
| --- | --- |
| `vain_stage_curtain.glb` | 两侧垂幔以不同相位缓慢起伏；掌声响起时轻轻向外荡开，停止后回到展开度更小的静止姿态。 |
| `vain_mirror_petal.glb` | 待机时各镜以不同相位缓慢开合 `0.8°–1.5°`；鼓掌时向外张开，停止后回到更紧的角度。 |
| `vain_character.glb` | 待机呼吸、嘴部单独开合；镜头靠近时头部轻微追随玩家。 |
| `vain_hat.glb` | 第一轮台词中抬起帽子，等待掌声；收到掌声后短暂悬停，再压回帽檐。 |
| `vain_prince_applaud.glb` | 玩家触发“为他鼓掌”后双手合拍三至五次；只在动作使用期间显示，或与默认站姿交叉淡入。 |
| `vain_ring.glb` / `vain_ring_star.glb` | 金环极慢转动；掌声峰值时星形扣件亮起，停止后回落到低光。 |
| `vain_petal_fx.glb` | 掌声时从镜亭和立镜底部向上卷起少量花瓣；完成后缓慢落回。 |
| `vain_mirror_fan.glb` | 不独立交互，只随主镜做有延迟的亮度变化，形成后方闪光的层次。 |

推荐流程：进入场景 → 与角色交谈 → 触发“为他鼓掌” → 帽子抬起、金环发亮、花瓣与镜光弹出 → 掌声停止 → 角色再次等待赞美。玩家重复鼓掌时反馈幅度逐次变短，最后留下停住的镜子与一个未得到回答的问题。

## 必须写入 GLB 的交互挂点

- `CharacterRoot`：角色整体接地与布局编辑原点。
- `ValanceRoot`、`CurtainLeftRoot`、`CurtainRightRoot`：帷幔楣与左右垂幔的独立根节点。
- `TieBack_L`、`TieBack_R`：两侧金色束带与穗饰的固定点。
- `VainHeadPivot`：角色头部朝向和轻微点头的旋转轴。
- `JawPivot`：嘴部开合轴。
- `Arm_L_Upper`、`Arm_R_Upper`、`Hand_L`、`Hand_R`：动作和脱帽姿势。
- `HatGrip`：帽子抓取、抬手和放回帽檐时的中心。
- `MirrorPivot_01`–`MirrorPivot_10`：十个主立镜的开合轴，建议把空节点保留在场景层，不强求保存在同一个 GLB。
- `MirrorGlass_01`–`MirrorGlass_10`：带镜面材质、可单独调节亮度的面。
- `MainMirrorTarget`：允许启用实时反射的主镜中心。
- `ApplaudHand_L`、`ApplaudHand_R`：小王子双手合拍轴。
- `PetalSpawn`：纸花瓣主要发射位置。
- `RingAxis`：金环旋转轴。
- `RingStarSocket`：菱形星扣的单独挂点。

## 材质、导出与性能

- 色板：珍珠白 `#F1EAF3`、淡紫 `#B9A6C7`、云母蓝 `#B8D6EA`、暗紫灰 `#766A82`、低光泽淡金 `#CDB787`。
- 主体材质为哑光纸浆、柔面石材和低光泽金属；只有镜面可以反光。
- 单文件建议低于 10 MB；基础色纹理最大 `1024×1024`，法线和粗糙度最大 `512×512`。
- 花瓣、镜片、岩块共用纹理图集和材质；同模型优先 Godot 实例化，不复制网格。
- 所有独立道具统一 `+Y` 朝上，底部接触点位于本地 `Y=0`；基底以中心为枢轴。
- 镜亭顶部、立镜、角色和帽子分别保留独立根节点，便于现有布局编辑器和后续镜头取景。
- 导出前应用缩放，检查法线、双面材质和透明排序；不要导入超百万面的生成式原始模型。

1. 星球基底、镜亭、淡紫色金边舞台帷幔、一面主镜资产、金环和角色。

3. 镜亭与镜面的掌声动画、纸花瓣和镜光粒子。
4. 岩块、花瓣堆及背面少量装饰。
5. 中央镜面的年龄感变化、重复鼓掌降幅等扩展表达。
