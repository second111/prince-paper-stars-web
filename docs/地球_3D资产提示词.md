# 地球 · 狐狸与麦田 · 3D 资产生图提示词

本文件沿用 `虚荣者星球_3D资产提示词.md`、`商人星球_3D资产提示词.md`、`玫瑰星球_3D资产提示词.md` 和 `星球底模生成提示词.md` 的写法。比例以现有 `assets/planets/fox-awake.png` 为准；整体构图和地标位置以用户提供的 `参考图/地球/整体概念图.png` 为准；纸质厚度、块面密度、柔和暖光和手作微差参考 `rose-awake.png`、`merchant-awake.png` 与 `vain-awake.png`。星球基底只负责完整地形壳、S 形土路和裸露的麦田种植区；洞穴、麦子、苔藓、岩石、狐狸、小王子与金环全部作为独立资产放置。地球基底使用一张横向双视图参考图：页面上并排放两颗完整星球，左边是正面，右边是同一颗星球的背面。

## 使用原则

- 整体效果图只用于确认构图、比例、材质和层次，不直接作为一张不可拆分的 3D 模型。
- 单资产图只生成一个物体，使用暖白纯色背景，不生成星球、地面或其他场景物件。
- 单资产图通常只包含一个物体和一个相机视角；星球基底是唯一例外：一张宽幅图中必须并排放置两颗同尺寸、同材质的完整星球，左侧显示正面，右侧显示同一颗星球的背面。不要生成第三颗，也不要让左右变成两个不同世界。
- 星球基底必须是封闭、连续、没有洞腔、没有草簇、没有悬空装饰的完整球体。不要把洞穴、岩块或植被烘焙进基底。
- 麦田预留区使用暖赭色裸土，不使用绿色草坪铺底。麦穗、苔藓和草叶都必须在基底之外单独制作。
- 洞穴必须是独立的 `earth_burrow.glb`：带真实厚度的土丘外壳、内凹入口和贴合球面的弧形底面，不依靠在基底上挖洞。
- 麦子不按“一根麦子一个文件”拆资产。先制作密集麦丛，再做成小型麦田瓦片，最后用 `MultiMeshInstance3D` 贴球铺设。不要生成带厚土台和竖直侧壁的大弧形麦块。
- 狐狸首版只生成静态模型；头、下颌、耳朵、四肢和三段尾巴拆成独立节点，动画后续再实现。
- 二维参考图没有小王子。小王子坐地等待的提示词属于按项目既有角色体系补充，不声称是二维图还原。
- 后方淡米色雾带、日落太阳、星点、浮尘和风场属于场景系统，不单独做成 GLB。
- 二维图中没有树、房屋、风车、围栏或其他动物，本次不生成这些对象。

## 统一风格

每段提示词都保持：

- 儿童绘本式低多边形纸雕、刻木和微型模型质感。
- 像其他星球一样使用概括、厚实、可分层的体块；大块颜色之间要有雕塑感和纸片边缘，不做写实微纹理。
- 麦穗、麦秆和狐狸毛发都使用纸雕切面，而不是写实植物或绒毛。
- 暖麦金、暖橙、苔绿、深棕和旧金构成统一色板。
- 道具和角色使用三分之四正面镜头、轻微俯视和均匀柔光；星球基底使用接近赤道平面、仅 `2°–5°` 轻微俯角的正交镜头，避免生成顶部台地。
- 材质以哑光纸、柔面土石和低光泽金属为主。

## 麦田建模接口

当前参考图里的“厚弧形土台 + 稀疏直立麦穗”不适合直接接入麦浪系统，原因有三个：

- 土台会遮住星球表面，边缘出现明显厚墙，实例化时容易看到重复接缝。
- 麦子太稀，视线会落在棕色底板上，无法形成被风抚过的连续麦面。
- 整块地产物只能整体旋转；顶点着色器无法只弯曲穗顶而不拉动根部和侧壁。

正式资产改用以下结构：

1. `earth_wheat_clump.glb`：一簇密集麦子，用于近景和制作瓦片。
2. `earth_wheat_tile_a/b.glb`：由多簇麦子合并成的小型麦田瓦片，根部共面、顶部密集、边缘渐薄。
3. 在 Godot 中复制约 18–24 个瓦片，按球面法线旋转并轻微重叠覆盖。
4. 所有瓦片共用一个顶点风摆材质，根部固定在本地 `Y=0`，穗顶由高度权重控制弯曲。
5. 不在每根麦子或每颗麦粒上挂骨骼，也不使用逐根物理。

导入 Godot 后建议写入以下顶点属性：

- 顶点色 `R`：`0` 为根部、`1` 为穗顶，用于弯曲权重。
- 顶点色 `G`：每根麦秆的随机相位，用于打破同步摆动。
- 顶点色 `B`：麦穗与麦秆的材质区分，或保留给风后的明暗变化。
- 每个瓦片只有一个中心底部枢轴，原始朝向为本地 `+Y` 向上。

鼠标风场使用星球局部空间中的光标方向，不直接旋转瓦片节点。风场主要做两件事：顺鼠标运动方向弯曲穗顶，并沿球面法线轻微压入。这样麦田仍保持麦浪，不会变成整块刚体倾斜或毛绒贴片。

## 推荐生成顺序

1. 先提交整体效果参考图，确认麦田覆盖、狐狸、土路、洞穴和金环的位置与比例。
2. 用一张横向双视图提示词生成基底参考图，确认页面中正好有两颗同尺寸完整星球：左侧正面、右侧背面；两颗都必须球面连续且带裸土种植区。
3. 将这张双视图参考图提交给图生 3D，确认完整球体、封闭拓扑、裸土麦田种植区、内置 S 形土路和右中部洞穴预留区；基底中不得出现洞腔、平顶台地或任何草簇。
4. 生成密集麦田瓦片 A、瓦片 B 和边缘麦簇，再用单簇麦子调整近景密度。
5. 单独生成带真实洞腔和球面贴合底座的立体洞穴，再生成岩石；只有需要独立可编辑补片时，才生成土路和低矮苔藓模块。
6. 单独生成静态狐狸，检查尾尖、胸腹和四肢轮廓；不要混入麦田。
7. 生成小王子坐地等待姿势和金色轨道环。
8. 所有静态资产通过比例和轮廓检查后，再分别导入图生 3D。

## 生成后检查

- 星球是否完整向下收圆，没有平底、台座或地面。
- 双视图参考图是否正好包含两颗同尺寸星球，左侧正面、右侧背面，没有第三颗。
- 种植区是否包裹赤道、左右侧面和下半球，而不是只存在于平顶。
- 所有种植面是否都沿球面弯曲，没有平台、盆状田、环墙、切壁或阶梯状高台。
- 麦田是否占主导，而不是只有土路上的一块麦地。
- 麦子是否呈现为连续的密集穗面，而不是草坪、毛绒、细针或稀疏盆栽。
- 瓦片是否足够薄、根部共面、边缘渐隐，没有厚土台和竖直侧壁。
- 麦田瓦片是否可用于实例化铺设，没有把每根麦秆拆成独立资产。
- S 形土路、坡顶狐狸和右侧洞穴是否都能辨认。
- 狐狸是否为一只有橙红身体、奶白胸腹、深色腿部和白色尾尖的成年狐狸。
- 星球基底是否封闭、连续、无洞腔，并保留完整的下半球。
- 麦田预设区是否为暖赭色裸土，而不是绿色草坪。
- 基底与洞穴周围是否没有大簇草、叶莲座或抬高的草台。
