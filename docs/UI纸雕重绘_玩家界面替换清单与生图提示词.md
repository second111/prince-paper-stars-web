透明背景原图已保存在 `assets/ui/paper_ui/source/`，按组件拆分后的透明 PNG 位于 `assets/ui/paper_ui/`，并已接入 Godot 的封面、星图、详情、3D 场景和对话界面。

## 一、只生成以下内容

按当前保留项整理后，共 **13 类界面画材**。前两组来自已生成资产板，第三组中的提问横条由用户另行提供。

| 页 | 包含的 UI | 用途 |
| --- | --- | --- |
| 第 1 页：小型按钮与标记 | 封面主按钮、通用返回按钮、星球编号签、星球焦点环、对话气泡、鼠标点击引导标、擦拭布料、椅子放置点 | 按钮、入口、地面标记和拖拽物 |
| 第 2 页：大型纸卡 | 星球详情资料卡、3D 场景标题牌、对话主纸卡 | 承载标题与主要文字内容；折角关闭片直接画在对话主纸卡右上角 |
| 第 3 组：用户提供与复用 | 用户提供的对话选项纸签、短提示纸签 | 预设提问和底部操作提示 |

每个造型只生成一张默认状态。悬停、按下、禁用等状态在 Godot 中通过调亮、缩放、位移和阴影变化实现，不额外生成同款图。

### 已明确排除

- 星光收集系统：星光按钮、来源光环、记忆纸片、背包、星槽和第七星连线。
- 星球布局编辑器：入口、侧栏、对象列表、滑杆、数值框、复选框及编辑工具。
- 加载界面的横向进度条。
- 之前已删掉的封面标题饰条、独立语录板、独立关闭片和独立叙事字幕带。

所有中文均由 Godot 运行时叠加。生成图里不写文字，避免乱码和无法修改的死字。

## 五、第 3 组：对话文字与预设提问

- 对话上下文、居民发言和小王子发言直接作为文字排在大对话主卡中，不使用额外生成的发言底纸。
- 每个预设提问复用同一张用户提供的透明横条，由 Godot 改变颜色、亮度和按下时的位置反馈。
- 短提示纸签继续复用已有的 `hint_strip.png`。

## 六、生成与复用规则

1. 小型按钮与大型纸卡分别使用已生成的分页资产板，不再逐件单独生成。
2. 按钮、气泡、选项和提示纸只生成一个默认外观；悬停、按下、禁用由 Godot 调整颜色、亮度、缩放和投影，不另做同款素材。
3. 通用返回按钮生成一次，在星图、星球详情和 3D 场景共用。
4. 星球焦点环只做一套中性浅金色，六颗星球分别染色复用。
5. 对话主纸卡右上角的折角关闭片直接画在纸卡上，不再生成独立关闭按钮。
6. 对话选项纸签只使用一张用户提供的横条，程序按选项数量复制。
7. 鼠标点击引导标只生成一个，不再生成左、右、上、下等箭头版本；所有场景动作共用一个点击标记。
8. 擦拭布料只画一个默认状态，拖动时由程序改变光标和轻微旋转，不另做悬停或被抓起版本。
