# 爱慕虚荣者星球 · 3D 资产生图提示词

本文件沿用 `商人星球_3D资产提示词.md`、`玫瑰星球_3D资产提示词.md` 和 `星球底模生成提示词.md` 的写法。比例、构图和可见物体以现有 `assets/planets/vain-awake.png` 为准；先生成完整场景效果参考图，再分别生成单个资产，最后进入图生 3D。

## 使用原则

- 整体效果图只用于确认构图、比例、材质和层次，不直接作为一张不可拆分的 3D 模型。
- 单资产图只生成一个物体，使用暖白纯色背景，不生成星球、地面或其他场景物件。
- 每张单资产图只显示一个相机视角，不制作正面、侧面、背面转面拼图。
- 二维参考图没有爱慕虚荣的人和小王子。人物提示词属于按项目既有角色体系补充，不声称是二维图的还原。
- “一百面镜子”是剧情意象。场景用少量可交互主镜与浅浮雕镜片扇形表现体量，不制作 100 面完整立镜。
- 星图后的淡紫雾带、背景星空、浮尘、光晕和掌声界面不单独做 GLB。
- 现有 `rocks.glb`、`round_tree.glb`、`grass.glb` 可作远景回退，但本次不重复生成。

## 统一风格

每段提示词都保持：

- 儿童绘本式低多边形纸雕、微型建筑和精致手工玩具质感。
- 主体轮廓清楚，平面切面舒展，细饰集中在檐口、镜框和花形边缘。
- 珍珠纸、柔面石材、淡金和云母玻璃四种主要材质。
- 哑光表面，只有镜面允许低到中等的反射。
- 色彩克制，不做高饱和粉色或圣诞装饰感。
- 三分之四正面镜头，轻微俯视，均匀柔光。

## 推荐生成顺序

1. 先提交整体效果参考图，确认星球、镜亭、花瓣镜和金环的比例关系。
2. 单独生成星球基底，去掉镜亭、立镜、金环、花瓣和人物。
3. 生成开放圆顶镜亭与淡紫色金边舞台帷幔，再生成一面主花瓣镜和单个立镜底座。
4. 生成浅浮雕镜片扇形，用实例化补足镜群体量。
5. 依次生成金环、菱形星扣、岩块和花瓣堆。
6. 最后生成爱慕虚荣的人、礼帽、小王子鼓掌姿势和两种粒子资产。
7. 所有单资产通过比例和轮廓检查后，再分别导入图生 3D，禁止从整体效果图直接生成融合模型。

## 生成后检查

- 星球是否完整向下收圆，没有平底、台座或地面。
- 镜亭是否真正开放，八根细柱之间没有被墙体或玻璃封住。
- 舞台帷幔是否从两侧挽起，中央仍能看到镜亭地面。
- 花瓣镜是否有实体背壳，没有成为单面透明贴片。
- 主镜群是否保留中央入口，没有围成封闭的镜子墙。
- 金环是否细且连续，菱形星扣是否单独生成。
- 人物是否只有一个相机视角，并且没有把礼帽合并进角色。
- 镜面是否只反射柔和淡蓝云层，没有变成写实全场景镜面。
- 所有材质是否以哑光纸雕为主，没有高饱和粉色、婚礼蛋糕或圣诞装饰感。
