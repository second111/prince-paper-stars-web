# 地球 · 狐狸与麦田 · 3D 资产清单

## 场景目标

场景以现有 `assets/planets/fox-awake.png` 和 `fox-dormant.png` 为视觉基准：整颗金麦色星球、覆盖表面的流动麦浪、蜿蜒土路、右侧独立立体洞穴、少量低平苔斑和紫色岩块、站在坡顶的橙红狐狸、环绕下半部的细金环，以及后方淡米色纸雾带。

剧情和交互依据 `星球文本_定稿草案.md`，核心动作为“陪狐狸等到日落”。首版应让玩家先看见麦田、土路和狐狸，再通过时间推进让整片麦田逐渐变成暖橙金色，最后停在狐狸与小王子共同等待的构图上。地球的纸雕厚度、块面密度、柔和暖光和嵌石语言必须与玫瑰、商人、虚荣者星球保持同一套视觉体系。

当前工程只有地球的星图双态图，没有该星球的独立 3D 模型。首版目标为低模纸雕质感、可独立编辑，完整场景约 **32–35 万三角面**、**45 MB**。建议硬上限为 45 MB。

建议目录：

```text
GodotProject/assets/3d/earth/
```

## 比例与构图

以星球直径 `D=100` 作为统一尺寸基准：

| 项目 | 参考比例 | 说明 |
| --- | ---: | --- |
| 星球本体 | `100D%` | 必须是一整颗完整球体，下半球不截平。 |
| 麦田覆盖 | 可见上半球的 `75%–85%` | 保留 S 形土路、独立洞穴占地和少量低平苔斑作为呼吸区；麦田下方使用裸土，不使用绿色草坪。 |
| 狐狸高度 | `12D%–15D%` | 站在坡顶土路左侧，长尾向上卷起，不能缩成小挂件。 |
| 土路宽度 | `9D%–11D%` | 从画面左下向坡顶弯曲，宽度略不均匀，中央比两侧略浅。 |
| 洞穴开口宽高 | `10D%–14D%` | 位于星球右中下部，由独立立体模块提供带厚度的洞腔，并贴合球面；不是在基底上挖洞。 |
| 金环外径 | `110D%–116D%` | 环绕星球下半部，细且连续。 |
| 小王子高度 | `22D%–26D%` | 角色尺寸用于角色间关系，不照搬二维图比例。 |

二维图里没有树、房屋、风车、田野围栏或其他动物，本场景不添加这些元素。

## 可复用资产

| 现有文件 | 用途 |
| --- | --- |
| `rocks.glb` | 可作为洞穴边的远景石块，只需替换为灰紫与苔土材质。 |
| `grass.glb` | 地球场景不用于大面积铺草。若复用，只能缩成洞穴边的极短苔叶点缀，禁止形成截图中的大簇叶莲座。 |
| `standing_prince.glb` | 可作为加载和回退站姿；正式等到日落的镜头使用 `earth_prince_wait.glb`。 |
| `seated_prince.glb` | 只在其坐地姿态可重新调整为无椅姿势时复用；否则不要保留不可见的椅子。 |

`round_tree.glb`、`pine_tree.glb` 和任何房屋资产不用于地球场景。

## 场景外资产

以下内容不单独做成 GLB：

- 日落太阳、天空渐变和暖橙光带：使用现有场景灯光、着色器和程序化天体控制。
- 后方三层纸雾云带：沿用场景程序化云带，不烘焙进星球。
- 星点、萤火、浮尘和风中的少量麦芒：使用 GPUParticles3D。
- 剧情文字、对话气泡、等到日落的进度提示：属于 UI。
- 狐狸和角色的脚印、地面接触阴影：实时计算或贴花，不并入模型。

## 布局与可编辑对象

首版进入地球场景时，建议按二维图建立以下默认构图：

- 狐狸位于坡顶土路左侧，面向镜头偏左，尾巴向上卷到身体右后方。
- S 形土路从左下前景进入，绕到坡顶狐狸脚下；路线不能穿进麦田瓦片或洞穴洞口。
- 麦田瓦片可沿任意经纬度贴球铺设；基底从顶部、赤道到底部都是连续弧面，不得出现只适合在平顶区域种植的地形。
- 洞穴作为独立模块位于画面右侧中下部，洞腔朝画面左前方，周围保留裸土和少量低平苔斑，零散石头沿外缘布置。
- 麦田瓦片从洞穴后方、土路两侧和星球下半部叠放，边缘相互覆盖，避免形成规整同心环或梳齿状排列。
- 金环穿过星球下半部，在镜头中形成一条倾斜的细金线。
- 小王子默认坐在狐狸左后方半步，不遮挡狐狸和洞穴；等待完成时镜头稍微拉远，让角色与麦田同处一个画面。

所有独立根节点应能进入现有布局编辑器，支持位置、缩放、朝向、显隐和复制。

## 动画与交互

| 对象 | 动画或交互 |
| --- | --- |
| `earth_wheat_tile_a/b` | 所有实例共享顶点风摆材质；每片瓦片用不同相位和幅度起伏，鼠标局部风场直接弯曲穗顶，不旋转整块瓦片。 |
| `earth_wheat_edge_patch` | 小幅草叶摇晃，狐狸经过时做短促倒伏再回弹。 |
| `earth_fox.glb` | 待机呼吸、眨眼、耳朵转动、头部追随小王子或太阳，尾巴以二至三节慢摆；玩家靠近时头部先转，身体稍后才转。 |
| `earth_prince_wait.glb` | 呼吸、围巾轻摆、视线从狐狸转向落日；等待期间不播放夸张动作。 |
| `earth_burrow.glb` | 洞内保持克制的深色，完成等待后只在洞口落下一小片暖光，不出现眼睛或第二只动物。 |
| `earth_ring.glb` | 极慢绕球旋转，保持细线般的稳定运动。 |
| `earth_wheat_clump.glb` | 用于近景补密；风吹时整簇穗部随共享风场轻摆，不从瓦片中逐根拆出动画对象。 |

推荐交互流程：

1. 小王子进入场景，狐狸站在坡顶土路，风先吹动麦田。
2. 与狐狸交谈，触发“陪狐狸等到日落”。
3. 小王子移动到狐狸附近并坐下；狐狸转出头来。
4. 夕阳推进，麦浪由麦金逐渐变为暖橙，影子缓慢拉长。
5. 日光落下去，麦田仍保留微光；狐狸看向小王子。
6. 显示结束反思，不额外生成魔法光柱、花瓣爆发或第二个狐狸。

## 必须写入 GLB 的交互挂点

- `FoxRoot`：狐狸接地和布局编辑原点。
- `FoxHeadPivot`：狐狸头部左右追随。
- `FoxJawPivot`：狐狸说话时的下颌节点。
- `FoxEar_L`、`FoxEar_R`：双耳转动。
- `FoxTailRoot`、`FoxTailMid`、`FoxTailTip`：尾巴三段摆动。
- `FoxLeg_FL`、`FoxLeg_FR`、`FoxLeg_BL`、`FoxLeg_BR`：站立与坐下姿势切换。
- `FoxLookTarget`：狐狸视线中心。
- `FoxSitSocket`：狐狸转入坐姿时的地面接点。
- `WheatWindRoot`：麦田统一风向和相位基准。
- `PathStart`、`PathTopEnd`：土路两端，用于角色沿路移动；默认由基底内置路径提供。
- `BurrowEntrance`、`BurrowInside`：洞穴命中点与内腔中心。
- `PrinceRoot`：小王子整体接地和布局编辑原点。
- `PrinceHeadPivot`、`JawPivot`：看向狐狸与落日、嘴部开合。
- `PrinceHand_L`、`PrinceHand_R`：膝边动作和轻触地面。
- `SunsetLookTarget`：等待结束时镜头与角色共同关注的落日参考点。
- `RingAxis`：金环慢速旋转轴。

## 材质与导出规范

- 色板：麦金 `#D6A23A`、浅麦黄 `#E9C56D`、暖橙 `#C77735`、苔绿 `#87995C`、深棕 `#5B402D`、洞口墨褐 `#332721`、旧金 `#B58B3E`。
- 地球基底色板：金赭 `#C89756`、暖陶土 `#B77948`、柔和焦赭 `#9B603B`、深棕 `#5C412B`、土路灰黄 `#C5A36B`、灰蓝石 `#929798`、苔绿 `#6F8444`。基底使用三至四档清晰色阶，不使用连续深棕渐变或高饱和橙红。
- 麦穗和麦秆统一使用 2–3 套共享材质，不做逐穗独立纹理。
- 狐狸毛发使用哑光纸雕切面，橙红、奶白和深棕只表现大块色调，不追求写实绒毛。
- 土路与独立洞穴使用柔面土石和纸纤维质感，避免写实泥土地表。
- 绿色区域只允许低平苔面和极短叶点，不得在基底或洞穴上生成大型草团、草扇、叶莲座、高树或灌木墙。
- 单文件建议低于 10 MB；基础色纹理最大 `1024×1024`，法线和粗糙度最大 `512×512`。
- 所有资产统一 `+Y` 朝上；独立道具底部接触点位于本地 `Y=0`，星球基底以中心为枢轴。
- 麦田瓦片和草地保持可实例化，同一网格不要复制出十余份独立材质。
- 导出前应用缩放、检查法线与双面材质，不要导入超百万面的原始生成模型。

## 性能策略

- 整片麦田不使用数万根独立网格渲染；以两种密集瓦片实例化约 20 次，近景再补少量 `earth_wheat_clump.glb`。
- 远景瓦片降低密度或切换到简化网格，避免狐狸周围被高频麦穗遮住。
- 麦田、低平苔藓和岩块使用共享材质及 MultiMeshInstance3D；风摆通过同一着色器以不同相位驱动。
- 金环、麦芒粒子和远景雾带关闭高成本阴影。
- 狐狸与小王子的独立部件数量控制在动画所需范围内，不把每根毛或围巾褶皱拆成节点。

## 首版优先级

1. 先用一张横向双视图提示词生成基底参考图，页面内必须正好包含两颗同尺寸星球：左侧正面、右侧背面；再以同一球体尺度进行图生 3D。
2. 带全球裸土种植区和内置 S 形土路的封闭星球基底、一个麦田瓦片主模块、独立立体洞穴和狐狸。
3. 两种密集瓦片与边缘麦簇的实例化覆盖、独立洞穴安装和少量低平苔斑。
4. 麦浪、狐狸尾巴、狐狸头部追随与日落光色变化。
5. 金环、岩块和边缘麦簇。
6. 麦芒粒子、狐狸坐下动作和结束时的拉远镜头。

## 验收标准

- 从默认镜头看，星球仍像二维图一样以金色麦田为主要表面，而不是绿色草地或空旷土球。
- S 形土路、坡顶狐狸、右侧洞穴三个地标能在同一画面中清楚辨认。
- 星球基底是封闭连续、无洞腔、无草簇的可用地形壳，下半球完整。
- 地球基底与其他星球使用同一套厚纸雕、圆润低模大块面、分层土台和嵌入岩石语言，不能像光滑陶土球或水彩贴图球。
- 基底双视图页面正好包含两颗同尺寸星球，左侧正面、右侧背面；两者都是完整圆弧轮廓，种植区连续包裹侧面与下半球，没有平顶、盆状田、环墙或只能开垦顶部的台地。
- 麦田种植区是暖赭色裸土；基底和洞穴上没有大型草团、草扇或叶莲座。
- 麦田没有形成机械同心圆、梳齿状直行或完全相同的麦穗阵列。
- 麦田瓦片没有厚土台、竖直侧壁或大面积裸露土壤；实例重叠后形成连续麦面。
- 每根麦秆具有根到穗顶的高度权重，风场只弯曲穗部，不旋转整块植被瓦片。
- 狐狸的长吻、尖耳、白色胸腹和白色尾尖必须清楚，尾巴保持卷起轮廓。
- 洞穴是独立 GLB，带真实外壳厚度、深色内凹洞腔和贴合球面的弧形底座；不是木门、井口、烟囱或独立小屋。
- 场景中不出现树、房子、风车、围栏、其他动物或第二只狐狸。
- 小王子坐地等待时不带椅子，也不遮挡狐狸和洞穴。
- 日落变化只改变光线、天空和麦田色温，不生成火焰、爆炸或金色烟花。
