# 玩家星球 · 保存与拍照按钮生图提示词

## 一、统一风格

这两个入口必须与现有 `symbols/dialogue.png` 和 `symbols/sticker.png` 来自同一套手工纸片：暖米白旧纸、浅灰米黄纤维、暗旧金压线、深焦糖棕符号、极薄纸层与短而柔的接触阴影。图标本身就是一片略不规则的小纸片，不要再画圆形底板、渐变色块或现代 App 按钮。

建议输出两张独立透明 PNG；如果生图工具更擅长资产表，可用第三段的一次成图版本，再按等距两格拆分。

## 二、保存摆放

```text
生成一枚《小王子 · 纸雕星图》玩家星球右下角入口符号，单独物件，正面或轻微三分之四视角，纯透明背景。

主体是一片略微不规整的暖米白手工纸小卡，像从旧童话手工册里剪下的收藏夹。外轮廓是自然手剪的柔和小起伏，不能出现厚圆环、糖果式倒角或立体圆盘。纸面有极细天然纤维、轻微压痕和一条很淡的旧金窄压线。纸张厚度约一片纸，只有短、柔、干净的接触阴影。

纸片中央用深焦糖棕旧印泥画一枚简洁的“收藏/保存”符号：一个窄长纸页夹，内部只有一枚小星星和一条短横线，形象安静、克制、好认；不要画现代软盘、齿轮、云端上传箭头或手机图标。纸片右上角可以有一小片暗旧金的三角折角，折角面积很小，不抢中心符号。整体像童话旅行者把一颗星球认真收进自己的手记。

紧凑正方形构图，主体完整、居中，占画布约百分之七十二，四周透明留白充足。缩小到 44 至 52 像素后，收藏夹、星星和折角仍能清楚辨认。暖米白、浅灰米黄、暗旧金、深焦糖棕配色，和现有对话气泡、贴纸入口的纸色、纤维密度、描边粗细、光照方向完全一致。

不要人物、文字、字母、数字、伪文字、爱心、表情脸、现代软件图标、厚纸板、塑料、玻璃、亮面金属、霓虹、强发光、白色背景、棋盘格、圆形底板、多个图标、水印或贴边裁切。
```

## 三、拍照生成信纸

```text
生成一枚《小王子 · 纸雕星图》玩家星球右下角入口符号，单独物件，正面或轻微三分之四视角，纯透明背景。

主体是一片略不规则的暖米白手工纸小相片卡，继承现有贴纸入口的纸张纤维、柔和手剪边缘和极薄纸层。纸片近似方形，但四边有非常轻的自然裁切起伏，不能做现代圆角按钮，也不能有厚实外框。纸张接近平面，只有一片薄纸的厚度和短、柔、干净的接触阴影；左上角有很轻的暖光。

纸片中央以深焦糖棕旧印泥画一台极简纸雕相机：圆钝的小机身、一个清楚的大圆镜头、顶部一颗微型取景按钮。镜头旁只留一点点奶油色纸光，不画真实反光。相机右上角叠一颗很小的暗旧金纸星，暗示照片会变成来自星球的纪念信纸。符号线条简洁、圆钝、略手作，缩到 44 至 52 像素仍然一眼可读。

构图紧凑，相机主体完整、居中，占画布约百分之七十二，四周透明留白充足。不要出现胶囊按钮、圆底、厚外框、现代相机品牌、镜头文字、闪光灯爆炸、照片缩略图、纸飞机、人物、爱心、文字、字母、数字、伪文字、塑料、玻璃、亮面金属、霓虹、强发光、白色背景、棋盘格、多个图标、水印或贴边裁切。整体必须与现有对话、贴纸入口像从同一张星球编号签上裁下来的小纸片。
```

## 四、一次生成两枚素材表

```text
生成一张横向 2 列 × 1 行的《小王子 · 纸雕星图》玩家入口符号素材表，画布比例 2:1，纯透明背景。只包含两个互不接触、互不跨越分界线的纸片图标，不要人物、表情列表、面板或按钮底板。

统一美术语言：暖米白旧纸、浅灰米黄天然纤维、暗旧金窄压线、深焦糖棕旧印泥符号；极薄手工纸片，边缘是细小的自然裁切起伏，不做厚圆环和糖果式倒角；左上暖光，短而柔的接触阴影。整体与现有对话气泡和贴纸入口完全同源。

左格是“保存摆放”入口：一片略不规则的暖米白纸卡，像小小收藏夹；中央只有一页窄长收藏夹、一颗小星和一条短横线，右上角有一小片暗旧金折角。它表达把当前星球布置认真收好，不画软盘、齿轮、云端或现代 App 保存图标。

右格是“拍照生成信纸”入口：一片略不规则的暖米白纸相片卡；中央只有圆钝的极简纸雕相机、一个大圆镜头和一个小取景按钮，右上角叠一颗很小的暗旧金纸星。它表达为星球拍一张会变成手作信的纪念照，不画真实品牌、镜头文字、照片缩略图或强闪光。

两枚图标大小、纸色、纸层厚度、纤维密度、描边粗细、符号复杂度和光照方向完全一致；各占本格约百分之七十二，完整居中，四周与两格之间保留充足透明间距，便于拆分和缩小到 44 至 52 像素。不要文字、字母、数字、伪文字、人物、爱心、圆底、胶囊底板、白底、棋盘格、玻璃、塑料、亮面金属、霓虹、水印、重复图标或贴边裁切。
```

## 五、导出与接入

- 每枚建议输出至少 `1024 × 1024` PNG，sRGB，真实透明背景。
- 主体安全区保持居中，四边透明留白不少于画布宽度的 `12%`。
- 保存为 `save.png`、`camera.png`，放入 `assets/ui/player_interactions/symbols/`。
- 游戏内显示尺寸约 `52 × 52`，不要额外套圆形底板；悬停只做轻微提亮和 `2%–3%` 缩放。
