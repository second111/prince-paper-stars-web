# 商人星球 · 3D 资产清单

## 整理口径

场景以现有 `assets/planets/merchant-awake.png` 和 `merchant-dormant.png` 为视觉基准：墨蓝与赭石拼接的小星球、由账簿和抽屉堆成的计数房、巨大算盘立面、尖顶塔楼、上锁的大柜、黄铜星签、暖色小灯和细金环。剧情与交互依据 `星球文本_定稿草案.md`，核心动作为“帮他核对一颗星”。

当前只有星图双态图，尚无该星球的 3D 模型。首版目标为低模纸雕建筑、可独立开合与计数，完整场景约 **30–34 万三角面**、**50 MB 以内**。

建议目录：

```text
GodotProject/assets/3d/merchant/
```

## 复用与场景外资产

| 现有文件 | 用途 |
| --- | --- |
| `round_tree.glb` | 星球左右边缘的 3–4 棵圆冠树；复制后改用墨绿和灰绿材质，不要使用玫瑰星球的鲜绿。 |
| `rocks.glb` | 大陆边缘与金环附近的 3–5 组灰青色岩石。 |
| `standing_prince.glb` | 可作为加载、回退或非交互站姿；正式抽屉交互使用 `merchant_prince_reach.glb`。 |
| `grass.glb` | 仅少量用于背面和边缘，正面以硬质账房建筑为主。 |

以下内容不建议做成独立 GLB：

- 悬浮星点和被编号的远景星空：由场景着色器和粒子完成。
- 星球后的淡金纸雾带：沿用现有程序化云带。
- 账本上的文字、抽屉编号和星签数字：由 `Label3D`、贴花或界面动态生成。
- 交互气泡、核对按钮、对话框：属于 UI。
- 单个星星模型：本段剧情的关键反转是“抽屉里只有纸牌”，不应增加一颗被收藏的星。

## 计数房结构建议

参考图是信息密度很高的建筑群，建模时应按“前景交互区、中景主体、远景轮廓”三层拆分：

- 前景交互区：抽屉组、厚柜、小王子伸手姿势、地面暖灯。
- 中景主体：左侧账簿堆、中央算盘高塔、后方账柜。
- 远景轮廓：两座尖塔、悬挂星签、树冠和星球边缘岩块。

远处两座塔和账簿堆不用精细雕刻每一本书，书的厚度、纸页侧边和铜角要清晰即可；从默认镜头距离看不出的小细节应删面，不应靠极高模硬撑。

## 建议动画与交互

| 对象 | 动画或交互 |
| --- | --- |
| `merchant_character.glb` | 待机呼吸、低头记账、嘴部独立开合；玩家交谈时抬头但不停止手里的小幅记账动作。 |
| `merchant_prince_reach.glb` | 触发“帮他核对一颗星”后右手伸向抽屉把手，拉开后保持伸入姿势。 |
| `merchant_drawer_bank.glb` | 选定抽屉先向外滑出，再轻微下垂；关闭时有短促回弹。 |
| `merchant_star_card.glb` | 抽屉打开后纸牌从内部翻起或轻微抽出，牌面空白星形边框变亮；数字只显示在纸牌旁的短标签上。 |
| `merchant_abacus_bead.glb` | 核对过程中对应横杆的十枚中有一枚滑动，随后另两根横杆作出短促回应；不要整座算盘同时高速抖动。 |
| `merchant_star_tag.glb` | 与抽屉里的数字同步转动和闪烁一次；核对完成后远空对应星点熄灭。 |
| `merchant_lantern.glb` | 暖灯常亮并有极弱呼吸；核对成功时短暂增亮，结束后恢复到偏冷、偏暗状态。 |
| `merchant_ring.glb` | 极慢绕球旋转，圆珠连接件保持固定金属反光。 |
| `merchant_strongbox.glb` | 首轮对话时轻触锁扣但不真正打开；核对结束后才允许柜门打开，内部依然空着。 |

推荐流程：进入场景 → 与商人交谈 → 选择“帮他核对一颗星” → 小王子拉开指定抽屉 → 算珠移动、星签编号变化 → 纸牌露出 → 星空少一个亮点、抽屉合上 → 商人松了一口气。全程不出现一颗被释放或被收藏的星星。

## 必须写入 GLB 的交互挂点

- `CharacterRoot`：商人整体接地与布局编辑原点。
- `MerchantHeadPivot`：抬头、低头与看向抽屉的旋转轴。
- `JawPivot`：嘴部开合轴。
- `Arm_L_Upper`、`Arm_R_Upper`、`Hand_L`、`Hand_R`：翻账本与指向抽屉。
- `BookPointer`：商人手持短笔或算筹的独立替换点。
- `DrawerSocket_01`–`DrawerSocket_03`：抽屉组内三个宽抽屉的滑轨原点。
- `DrawerHandle_01`–`DrawerHandle_03`：交互命中区和拉手中心。
- `DrawerInteract_01`：首版剧情强制打开的核对抽屉，应明显区别于其余五个。
- `ReachHand_R`：小王子伸手抓握点。
- `CardSocket`：纸牌翻起和抽出时的中心。
- `NumberRoot`：数字动态标签的定位与朝向基准。
- `AbacusRod_01`–`AbacusRod_06`：六根横向圆杆的独立节点；每根杆只需连接左右边框，杆身和杆间空隙不得被竖板或背板封住。
- `BeadStart_01`–`BeadStart_06`：每列第一枚算珠的定位点。
- `TagHang_01`–`TagHang_12`：星签挂点和摆动轴。
- `LanternGlow_01`–`LanternGlow_04`：灯罩内部发光面和局部光源锚点。
- `StrongboxHinge`：柜门旋转轴。
- `EmptyChamber`：柜内空腔中心，交互后只能有空气和阴影。
- `RingAxis`：金环旋转轴。

## 材质、导出与性能

- 色板：墨蓝 `#26394A`、赭黄 `#C99B50`、旧金 `#B08A43`、烟熏蓝绿 `#5E7774`、奶油纸 `#D7C9A9`。
- 账本封皮和抽屉使用低反射木纹/皮革纸质，不用高光塑料；金属仅限铜扣、算盘杆、星签和锁。
- 数值、编号和字形不能烘焙进基础色纹理，避免无法切换或本地化。
- 单文件建议低于 10 MB；基础色纹理最大 `1024×1024`，法线和粗糙度最大 `512×512`。
- 十二枚星签、四盏灯、五十枚算珠都用同一主网格实例化；不把每枚小物件导出成单独文件。
- 独立建筑统一 `+Y` 朝上，底面接触点放在本地 `Y=0`；基底以中心为枢轴。
- 两座塔、账簿堆、账柜、大柜、抽屉组和角色保留独立根节点，便于现有布局编辑器选中、隐藏和调整。
- 正面小物件关闭高成本阴影；灯罩只做自发光，不投射动态阴影。
- 导出前应用缩放，补算法线和切线，检查双面窗口、柜门与抽屉的穿模。

## 首版优先级

1. 星球基底、抽屉组、大柜、中央算盘塔和商人角色。
2. 左右账簿结构、两座尖塔、金环和小王子伸手姿势。
3. 可开合抽屉、数字纸牌、算珠和星签动画。
4. 四盏灯、台阶、树与岩块。
5. 远空星点熄灭、空柜内阴影和完成后的余韵镜头。
