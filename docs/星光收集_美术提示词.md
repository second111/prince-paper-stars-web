# 星光收集系统 · 美术资产与生图提示词

当前版本使用程序化占位图形，玩法、状态保存和动画已经接入。后续替换正式资产时，优先保持以下画布位置和透明边界不变。

## 统一风格

手剪纸雕、多层纸张、温暖童话、明显但不锋利的纸纤维边缘，低饱和深蓝星夜配色，金色只用于星光和交互提示。保持与现有《小王子 · 纸雕星图》一致的 2D 纸偶、折痕和柔和阴影。

避免：塑料质感、写实 3D 渲染、强霓虹、复杂粒子、厚重黑描边、现代 UI 图标、圆形叉号、文字水印。

## 4. 星光生成源

每颗星只需要一张轻量透明光效，建议 `512×512`，不要遮挡原物件。

- 玫瑰：玻璃水汽中凝出的细金纸屑，像雾被轻轻卷起。
- 国王：太阳边缘被风吹落的一圈余晖。
- 虚荣者：镜心聚成一点的光，不出现完整倒影。
- 地球：日落麦浪之间升起的小纸星。
- 商人：沿无编号灯串逐盏聚拢的蓝色微光。
- 点灯人：从灯焰顶部脱离的一小片火星纸屑。

通用提示词：

> A very light hand-cut paper magic effect for [SOURCE], loose gold fiber glints and translucent colored paper dust gathering into a small star shape, sparse and elegant, no sparkle overload, no lens flare, transparent background, 2D paper theater animation style.
