# 星球 3D 布局编辑

星图中的玫瑰、爱慕虚荣的人、商人和狐狸与麦田现在都会进入 3D 星球场景。

## 调整物件

1. 点击星图上的星球进入 3D 场景。
2. 点击右上角齿轮打开“星球布局编辑器”。
3. 从可滚动的物品列表选择一个物件；列表也能选中被星球地形遮挡的物件。
4. 直接拖动物件可沿星球表面移动；右侧滑杆可继续调整缩放、朝向和离球心距离。离球心范围现在支持 `1.5～8.0`。
5. 场景空白处左键拖动可旋转星球；编辑时也可以使用右键或中键拖动，避免物件遮挡造成镜头无法旋转。
6. “镜头距离”可在 `2.8～24.0` 之间调整；鼠标滚轮也可以拉近或拉远视角。
7. 旋转到满意的正面朝向后，点击“将当前朝向设为初始视角”；重新进入场景或双击复位时会恢复该朝向。
8. 使用“画面高度”中的“星球上移 / 星球下移”调整初始构图中的上下位置。朝向和画面高度按星球分别保存。
9. “球面倾角”为物件相对当前落点球面的角度：
   - `0°`：物件基座垂直于落点切面；
   - `-1° / +1°`：沿球面切线小幅倾斜；
   - “贴地”：将倾角恢复为 `0°`；
   - 滑杆：在 `-60°` 到 `+60°` 之间微调。
10. 需要保留多个同款物件时使用“复制对象”。
11. 调整完成后点击“保存布局”。

每颗星球使用独立布局文件：

- `rose_layout.json`
- `vain_layout.json`
- `merchant_layout.json`
- `earth_layout.json`

布局同时保存到项目目录和用户数据目录。下次进入同一颗星球时会优先恢复用户保存的版本。

## 当前基础内容

- 玫瑰：14 个环境物件，包含新增的玫瑰模型、圆冠树、针叶树和草丛
- 爱慕虚荣的人：12 个环境物件
- 商人：13 个环境物件
- 狐狸与麦田：8 个环境物件

四颗星球都加入了点灯人场景使用的圆冠树、针叶树和草丛。植被的朝向由落点法线决定，不再随镜头旋转。

人物和动物没有默认放入场景。玫瑰目录中的坐姿小王子、地球目录中的狐狸等模型保留在资源目录中，便于之后单独布置。
