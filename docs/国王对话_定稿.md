# 国王星球 · 对话定稿

玩家以小王子的身份与国王交谈。三组问题可以自由追问；进入核心分支后，小王子必须亲手让太阳升起、再让太阳落下。完成一次完整的昼夜交替后，流程结束。

## 初次交谈

**国王**：啊，来了一位臣民。走近些，让我看看你。

**国王**：我统治星星、天空，还有你脚下的这颗星球。

预设提问：

1. 这里除了您，还有谁可以统治？
2. 如果没有人服从，命令还算命令吗？
3. 您能让太阳现在就落下吗？
4. 那么，您想让我做什么？

## 自由追问

### 这里除了您，还有谁可以统治？

**国王**：至少现在有你。你看，我的星球终于有了第二位居民。

*旁白：他把“第二位”说得很轻，像怕那两个字也会被风吹走。*

### 如果没有人服从，命令还算命令吗？

**国王**：命令先留在我的口中；只有当另一个人回应，它才会变成现实。

*旁白：他望向空空的台阶，仿佛那里仍站着未曾离开的臣民。*

### 您能让太阳现在就落下吗？

**国王**：我当然可以命令它。但太阳只应在该落下时落下。

**国王**：权威首先必须合理。若一道命令违背世界，那不是世界失了礼，而是我说错了时间。

*旁白：他抬起头，没有立刻开口下令。*

## 进入核心分支

**国王**：我命令你留下。

**国王**：你看，我没有让你做做不到的事。这是一道多么合理的命令。

*旁白：他说完，悄悄看了一眼身后的王座，像在确认它是否还在。*

可选回答：

- 仅仅留下，不能证明您的权力。
- 那就给这颗星一道真正需要的命令。
- 如果我拒绝呢？

### 仅仅留下

**国王**：难道忠诚不是从一件小事里才看得见吗？

**小王子**：可小事也需要有人真心愿意。

### 真正需要的命令

**国王**：真正需要的命令？

**国王**：我已经太久只对空椅子说话，竟忘了世界也会向我提出要求。

**小王子**：那就先听一听星星正在做什么。

### 如果我拒绝

**国王**：那我就命令你不许拒绝。

**国王**：……这句话听起来，比前一句还要空。

**小王子**：不让人拒绝的权力，只是在对自己说话。

## 国王的反思

**国王**：我总想让星星、太阳和你都停下来，好让这顶王冠继续有分量。

**国王**：可如果世界真的停了，我还能命令谁去做什么呢？

*旁白：王座旁的小灯照着一段落满灰尘的旧命令。红毯尽头，仍然没有人应声。*

**小王子**：让太阳升起吧。我陪您完成一次昼夜。

## 一次完整的昼夜

**国王**：好。不是替王冠，也不是替我。只替这颗还在转动的星。

*旁白：他把扶着王座的手慢慢抬起来，像第一次松开一件并不属于自己的东西。*

点击“结束对话”回到场景。字幕出现：

> **帮小王子让太阳升起**

太阳旁出现无文字点击引导。玩家点击太阳后，天体开始旋转；旋转完成再出现字幕：

**国王**：你听见了吗？世界回应了。

**国王**：太阳升起时，我没有失去权力，反而第一次知道该把命令放在哪里。

*旁白：晨光越过王座，也照亮了那张空了太久的侧座。*

> **帮小王子让太阳落下**

玩家再次点击太阳。日轮落下并完成旋转后，流程结束。

## 结局

**国王**：一天结束了。

**国王**：我没有让任何东西停下。可这一天，确实因我们两个人而完整。

*旁白：小王子向国王行礼。不是因为王冠拥有命令一切的力量，而是因为国王终于允许世界按自己的方向转动。*

*旁白：一个从不允许别人拒绝的权力，得到的究竟是服从，还是一场缓慢的消失？*
