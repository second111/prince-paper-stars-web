# 玩家物品操作图标生图提示词

以项目现有的 `planet_tag.png` 星球编号签为唯一风格基准，不要参照现代手游圆形按钮。生成一张横向排列 5 枚圆形纸雕图标的透明背景 UI 素材表。

视觉必须直接继承星球编号签的质感：暖米白、浅灰米黄的旧纸色，低饱和且略发灰；纸面有非常细的天然纸纤维、轻微压痕和细小折皱；边缘是薄纸自然裁切后的极细小起伏，不能变成整齐的厚圆环。编号签左端的旧金压纹可作为圆形图标上的窄双线装饰，但必须平贴纸面、颜色偏暗、边缘自然磨损。

五枚图标都是单片薄纸圆形的感觉，纸层极薄，和编号签一样接近平面。圆形纸片只允许有约 0.3 毫米的纸张厚度和极短、极轻的接触阴影。严禁厚重棕色外圈、糖果式倒角、立体浮雕圆盘、亮面高光、玻璃质感、塑料质感、现代商业 App 图标和厚重 3D 卡片。

建议使用的颜色范围：

- 主纸色：暖米白 `#EDE5CE` 到浅灰米黄 `#DED4B8`；
- 旧金装饰：低饱和暗金 `#AE8A50`；
- 细边和轻投影：灰褐 `#8D7757`；
- 图标符号：深焦糖棕 `#5A381E`。

每枚圆形按钮内只放一个单一符号。符号像深棕色旧印泥压在纸上，或一片极薄纸雕贴合纸面，不做明显凸起：

1. 锁定：简洁的传统挂锁。
2. Z 轴左转：明确的逆时针弧形回转箭头。
3. Z 轴右转：明确的顺时针弧形回转箭头，与左转严格镜像。
4. 复制：两张轻微错位的纸页剪影。
5. 删除：简洁的纸篓剪影，可有两三条细小镂空线。

五枚按钮的直径、纸色、低对比度、纤维密度、符号粗细和光照方向必须完全一致，像从同一张星球编号签上裁下来的五个圆形小纸片。符号在缩小到约 34×34 像素后仍应清楚，不要添加文字、编号、伪文字、星星、藤蔓、花纹或额外装饰。

纯透明背景，不使用白底、棋盘格或任何背景纸。五枚图标横向等距排列，完整、独立、互不重叠，四周保留透明留白。输出 2048×512 或更高分辨率 PNG，sRGB，无边框、无水印、无裁切。
