# 商人星球 · 3D 资产生图提示词

本文件沿用 `玫瑰星球_3D资产提示词.md`、`建模参考图提示词.md` 和 `星球底模生成提示词.md` 的写法。比例以现有 `assets/planets/merchant-awake.png` 为准，先生成完整场景效果参考图，再分别生成单个资产，最后进入图生 3D。

## 使用原则

- 整体效果图只用于确认构图、比例、层次和色板，不直接作为一张不可拆分的 3D 资产。
- 单资产图只生成一个物体，使用暖白纯色背景，不生成星球、地面或其他建筑。
- 二维参考图中没有商人和小王子，人物提示词属于按项目既有角色体系补充，不能声称是二维图内容的还原。
- 二维参考图没有清晰独立的台阶，本次不写单独台阶提示词。正式布局可让建筑底部直接贴合球冠，避免凭空添加楼梯。
- 现有 `round_tree.glb`、`rocks.glb`、`grass.glb` 可复用，本次不重复生成植被和岩石提示词。

## 统一风格

每段提示词都保持：

- 儿童绘本式低多边形纸雕、刻木和微型模型质感。
- 概括、厚实的体块，干净平面切面，不做写实细微雕刻。
- 哑光纸、旧木、低光泽黄铜与柔面石材。
- 只保留三到四阶主要色块，以轮廓、厚度和明暗关系表现细节。
- 三分之四正面镜头，轻微俯视，均匀柔光。
- 不靠高光、镜面反射或复杂纹理制造可读性。

### 两张参考图落地建议

- 先分别生成两张单资产参考图，不要在同一张图里同时出现展开和卷起版本。
- 展开账卷的密集字迹应优先烘焙到 `1024×1024` 或更大的顶面贴图；图生 3D 只负责纸卷形体、厚度和卷曲层。
- 立卷的系绳和铜扣可以拆成独立材质区域，但应保留在同一个根节点下。
- 两个模型的底面建议都对齐本地 `Y=0`，横向轴线沿本地 `X`，便于直接放进现有布局编辑器。
- 在游戏中把展开账卷作为前景可读物件，把很高的立卷放在抽屉、账簿或算盘侧边形成纵向叙事呼应。

## 推荐生成顺序

1. 先提交整体效果参考图，确认星球与建筑的 `100 : 78–85 : 50–55` 比例关系。
2. 单独生成星球基底三视图，去掉所有建筑和轨道环。
3. 依次生成两本账簿、账簿堆下方的三层抽屉柜、算盘高塔、账簿柜、高塔、矮塔和上锁大柜。
4. 生成算珠、星签、纸牌和小灯，统一旧金与暖木材质。
5. 单独生成半展开账卷和卷起账卷，先用参考图确认纸卷轮廓、螺旋和字迹密度。
6. 单独生成金环。
7. 最后再按项目统一角色体系生成商人和小王子；不要把人物混入建筑参考图。
8. 所有单资产图通过轮廓和比例检查后，再分别导入图生 3D，禁止直接从整体效果图生成一整颗融合模型。

## 生成后检查

- 建筑群宽度是否约为星球直径的 `78%–85%`。
- 最高塔尖是否高出星球顶端约 `50%–55%` 个星球直径。
- 账簿堆、中央算盘、两座塔、大柜和抽屉是否没有增减为参考图中不存在的结构。
- 算盘是否为六根独立横向圆杆横跨开放槽口，杆间能透空，没有被竖向木板、隔条或背板粘住。
- 星球是否完整向下收圆，没有平底、台座或地面。
- 星签是否为空白星形，不出现乱码数字。
- 大柜内部是否为空，没有发光星星、金币或宝物。
- 所有材质是否保持哑光纸雕和旧铜质感，没有镜面金属或写实木纹。
