# 玩家星球 · 右下角按钮三联生图提示词

## 一、交付目标

为玩家星球右下角操作区撰写一套同源纸雕图标的生图提示词。现有 `dialogue.png` 与 `sticker.png` 是风格锚点，用它们的材质、纸边、配色、光照和缩小可读性作为参考；重新写“保存”和“拍照”，并新增“摆放”。

最终顺序固定为：

1. 摆放
2. 保存
3. 拍照
4. 对话（现有资源）
5. 贴纸（现有资源）

三枚图标放在同一张透明背景生成图中，按等宽三列排列。游戏内每枚宜显示约 `52 × 52`，不要额外叠圆形底板。

## 二、统一美术锚点

- 暖米白与浅灰米黄旧纸，纸面略发灰、不偏纯黄。
- 纸张有极细天然纤维、很轻的压痕和局部磨损，不做满屏噪点。
- 深焦糖棕纸层形成清楚但不过厚的侧边；旧金窄压线贴平纸面。
- 左上方暖光，接触阴影只落在右侧和下方，短、软、干净。
- 单片纸卡接近平面，厚度约一至两层纸；纸卡外轮廓略有手剪起伏。
- 符号只用深焦糖棕旧印泥色、旧金色和少量暖红纸色；缩小后轮廓仍要一眼可辨。
- 所有图标不写字，不画现代软件符号，不使用圆形按钮底板。

## 三、单次生图提示词（可直接复制）

```text
生成一张《小王子 · 纸雕星图》玩家星球右下角操作按钮的三联生图素材表，只用于游戏 UI 入口，不是游戏截图，也不是完整界面效果图。

如有参考图，第一张是现有“对话”气泡图标，第二张是现有“贴纸”图标。只参考它们的暖米白旧纸、深焦糖棕薄边、旧金压线、细纸纤维、左上方暖光、右下方短柔阴影和手作符号语言。不要修改参考图，也不要复制气泡或爱心主体。

背景必须是真实透明背景，保留 alpha 通道。画面中不画白底、灰底、棋盘格、桌面、星空或任何场景。

画布比例严格为 3:1，建议 1536×512 或 3072×1024。画面恰好分为三个等宽方格，但不要画出分界线、格子框或底板。从左到右固定为：摆放、保存、拍照。三枚纸卡的外接尺寸、纸色、纸层厚度、纤维密度、描边粗细、旧金压线粗细、符号复杂度和光照方向完全一致，像从同一本手作童话书里裁下来的三片纸。每个图标完整位于本格内并水平、垂直居中，主体约占本格短边的 72%；各格中心分别位于画布宽度的 1/6、1/2、5/6 处，图标互不接触、不跨格、不贴边。

统一风格：高级手剪纸雕 UI，单片薄纸卡和自然叠层纸边。主纸色为暖米白 #EDE5CE 到浅灰米黄 #DED4B8，纸面略发灰，纤维极细而稀；纸卡侧边用深焦糖棕 #5A381E，内侧只有一条低饱和旧金窄压线 #AE8A50。纸张厚度约一至两层纸，边缘有细小自然裁切起伏。符号使用深焦糖棕旧印泥或薄纸拼贴效果，不能像塑料、玻璃、亮面金属或现代 App 圆角图标。

左格“摆放”：一片略不规则的暖米白手剪纸卡，中央只有一块很小的等距纸雕星球地台、地台上的一把小椅子和一颗小纸星，左侧用四枚逐渐变小的金色圆点表示落位位置。它表达玩家自由布置自己的星球；不要画四向箭头、移动十字、下载符号或齿轮。

中格“保存”：一片同尺寸的暖米白手剪纸卡，右上角只有一小片旧金折角；中央只有一枚窄长的深焦糖棕收藏书签，书签内放一颗小金色纸星和一条短横线。它表达把当前星球布置认真收回旅行手记；不要画软盘、云朵、下载箭头、齿轮或现代保存按钮。

右格“拍照”：一片同尺寸的暖米白手剪纸卡；中央只有一台圆钝的纸雕相机，包括一个大圆镜头、一个小取景器凸起，机身由深焦糖棕和旧金薄纸叠成；相机右上方叠一颗很小的旧金纸星，暗示照片会变成来自星球的纪念信。镜头只保留一点奶油色纸光，不要真实玻璃反光、品牌、镜头文字、照片缩略图或爆炸式闪光。

三枚图标缩小到 52 像素后，摆放地台、收藏书签和相机镜头仍必须一眼可辨。只出现这三枚图标，每枚只出现一次，不要悬停、按下、禁用或彩色变体。

负面提示词：文字，汉字，英文，数字，伪文字，标题，标签，签名，水印，人物，小王子，场景背景，游戏截图，完整界面，多个图标版本，悬停状态，按下状态，分格线，网格，圆形底板，胶囊底板，现代扁平 UI，手机 App 图标，四向箭头，方向箭头，下载图标，云朵，软盘，齿轮，玻璃，塑料，亮面金属，霓虹，强发光，黑色粗描边，厚纸板，厚重 3D 浮雕，糖果式倒角，杂乱粒子，镜头光晕，物件重叠，跨格，贴边裁切，白色背景，灰色背景，棋盘格，半透明白色蒙版。
```

## 五、使用与拆分

- 参考锚点：`symbols/dialogue.png`、`symbols/sticker.png`。
- 建议生成尺寸：`3072 × 1024`，或同比例 `1536 × 512`。
- 生成后按三列等宽拆成 `place.png`、`save.png`、`camera.png`，再与对话、贴纸两枚旧图标并排使用。
- 五枚从左向右建议排成“摆放、保存、拍照、对话、贴纸”，保证操作顺序清楚。
- 必须保留真实 alpha 通道；不要把透明背景替换为白底、灰底或棋盘格。
