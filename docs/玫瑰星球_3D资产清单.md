# 玫瑰星球 · 3D 资产清单

## 场景目标

B-612 以现有星图卡片中的“莫斯绿球体、红玫瑰、玻璃罩、白色小屋、小火山”为视觉基准。首版互动聚焦“风来了，小王子把玻璃罩放回玫瑰身边”。资产应低多边形、纸雕感、可独立编辑，整体目标控制在约 **18–25 万三角面**、**50 MB 以内**。

## 可复用资产

| 现有文件 | 用途 |
| --- | --- |
| `standing_prince.glb` | 默认站立小王子，适合进入场景和对话。 |
| `round_tree.glb` | 圆冠树，可作为玫瑰场景背景植被。 |
| `grass.glb` | 草簇，可复制并替换材质颜色。 |
| `rocks.glb` | 石块，可复制并缩小放在道路和屋边。 |

## 建议动画

- `rose.glb`：花头缓慢呼吸，叶片在风强时轻颤；玻璃罩盖上后摆幅降低。
- `rose_glass_dome.glb`：拾取、抬起、移动、落下和轻微回弹；透明材质不参与阴影。
- `rose_baobab_sprout.glb`：按各自相位轻摆，被点击时可做果冻式回弹。
- `rose_gold_ring.glb`：非常缓慢地绕星球转动，星形节点保留微光。
- `rose_volcano_a.glb`：只做低帧率烟雾和极弱火光，不生成实时体积烟。
- `prince_rose_reach.glb`：只在玻璃罩落回底座时使用；其余时间显示站立小王子。

## 交互挂点

以下空节点建议直接写进 GLB：

- `LightAnchor_Window`：小屋窗户暖光。
- `LightAnchor_Volcano`：火山口微光。
- `RoseHeadPivot`：玫瑰呼吸和朝向的旋转轴。
- `DomeGrip`：玻璃罩拖动时的抓取中心。
- `DomeSocket`：玻璃罩落回位置。
- `SmokeSocket`：火山烟雾发射点。

## 导出与性能约束

- 单文件建议低于 10 MB；整个玫瑰场景目标低于 50 MB。
- 三角面：主体星球 80k 内，玫瑰 35k 内，小屋 15k 内，其余单个摆件不超过 10k。
- 基础色纹理最大 `1024×1024`，法线和粗糙度最大 `512×512`。
- 多个小物件共用一张纹理图集，避免每个 GLB 重复嵌入三张 PBR 纹理。
- 玻璃罩关闭阴影；地表小花、草和金色轨道使用简化阴影或关闭阴影。
- 所有可移动物件保持独立根节点、统一朝上、底面位于本地 `Y=0`，便于现有布局编辑器接入。
- 不使用超百万面的生成式原始模型；建模完成后先减面，再导入 Godot。

## 首版优先级

1. 星球基底、玫瑰、玻璃罩和玻璃罩底座。
2. 小屋、石板路、小火山和金色轨道。
3. 小王子伸手姿势与“放回玻璃罩”动画。
4. 树、花草、栅栏、石块等装饰。
5. 拔除幼年猴面包树、花瓣晨露等扩展互动。
